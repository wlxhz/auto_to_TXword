# 智能表显示规则：一次配置，持续生效

目标：https://docs.qq.com/smartsheet/DVEFWWHprU0ZRa1Za?viewId=vJZ6Dq

服务器通过 Token 调用接口执行数据同步，不运行浏览器，不依赖网页登录 Cookie。Token 失效时需重新授权。下面的操作是在任意已登录且有编辑权限的浏览器中一次配置视图；保存后后续新增记录也沿用规则。

## 当天更新记录排在前面

在当前“表格视图”顶部的“排序”中，选择“最近同步变更时间”，设置降序（新时间在前），并启用自动排序（若界面提供开关）。随后在“表格设置”的字段显示设置中隐藏“最近同步变更时间”，保留 15 个业务字段可见。

脚本仅在新增或业务字段实际变化时更新该时间。人工字段变化、重复运行和序号差异不会刷新时间。这里排序的是实际同步变更时间，不是首次佩戴时间。

网页客户端降序排序会把空日期排在最前面，接口的记录排序却将空值放在最后，因此不能只验证接口。迁移时使用 `initialize_smart_sort.py --apply` 给缺少历史更新时间的旧客户补隐藏占位值 `1`（Unix 毫秒），专门表示“未知历史更新时间”，不是真实更新时间。它早于任何实际客户变更时间，使旧记录排到末尾；不能写成修复当天的时间。该工具仅修改隐藏字段，先备份并回读检查所有其他字段，支持重复执行。新客户由正式同步脚本写真实时间，不需要每日修复。

## 当天回访提示

进入顶部“填色”设置，对“一小时回访”“三天回访”“首次周回访”“取机器回访”分别设置日期条件：等于今天。使用动态“今天”，不要固定填写某一天，也不要选择“非空”或“早于今天”。范围应覆盖对应字段的所有记录，使新增客户自动沿用。

已在实际界面选择“浅红 2”单元格填充（`chromeRedLighten_4`），未开启整行填色。这是红色背景提醒，不是红色字体。原有蓝色表头规则保留。

验证：2026-10-02 数据中有 2 条取机器回访日期等于当天，它们应命中提示；其他日期不应命中。跨天后昨天的日期应恢复非提醒状态。
