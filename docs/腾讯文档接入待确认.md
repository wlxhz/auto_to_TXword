# 腾讯文档接入状态与上线条件

目标链接：`https://docs.qq.com/sheet/DVFd3U0x1cXNtTFRn`（用户提供）。

该链接路径为 `/sheet/`，看起来是普通在线表格。当前项目的“按客户读取原行并更新、新客户追加”实现基于智能表格的 `smartsheet.list_records`、`update_records` 和 `add_records`。腾讯文档官方 MCP 指南列出的普通 Excel `batch_update_sheet_range` 为末尾追加，不提供本项目需要的原行匹配与更新。因此，在确认目标表格类型和更完整的开放平台写入能力之前，`backend` 保持 `mock`，不得对真实台账执行写入。

官方接口参考：[腾讯文档 MCP 使用指南](https://developer.cloud.tencent.com/mcp/server/11803)。实际可用工具以授权账号调用 `tools/list` 为准。

上线前需完成：

1. 确认继续使用普通在线表格及其可读写指定单元格的开放平台授权方式，或改用腾讯智能表格。
2. 在目标表增加文本列“客户ID”和“最近更新日期”，并核对现有 15 列标题。先以副本测试旧行 UUID 回填、新客户新增和血糖更新。
3. 四个回访列均为文本，设置并验证“值等于今天的 `yyyy-mm-dd` → 红色字体”；不得把本地 Excel 的红字视为线上已生效。
4. 为“最近更新日期”设置降序排序视图，使当日更新行显示在前；不依赖物理搬动记录。
5. 在实际运行脚本的服务器环境设置 `TENCENT_DOCS_TOKEN` 和只读 `GLUCOSE_DATABASE_URL`，不要写进仓库。
6. 先只读验证文档、工作表和字段，再对测试副本执行写入并核对结果，最后才切换生产目标。
